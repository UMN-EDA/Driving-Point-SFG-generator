Install and run

You need Python 3.8 or newer and a C++11 compiler, such as g++. Graphviz is optional; Matplotlib supplies a plotting backend when dot is unavailable.

git clone git@github.com:UMN-EDA/Driving-Point-SFG-generator.git
cd Driving-Point-SFG-generator
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

python sfg.py 5T_OTA_Integrator_tran

The first run compiles the selected C++ engine. The wrapper prints the results directory, where report.html provides the graph and edge-gain table. Each run receives a separate timestamped directory under runs/.

Select an operation

ModeResult
graphGraph exports, PNG/SVG images, and HTML report; the default.
pathsGraph plus forward paths and symbolic path products.
loopsGraph plus cycles and symbolic cycle products.
analysisGraph, forward paths, and cycles.
transferOriginal C++ paths, loops, numerator, and denominator expressions.
# Graph plus paths and cycles
python sfg.py FirstOrderSCFilter --mode analysis

# Run a custom circuit
python sfg.py /path/to/my_circuit.isc --mode analysis

# Original C++ path and loop analysis
python sfg.py FirstOrderSCFilter --mode analysis --analysis-backend legacy

# Original symbolic transfer-function routines
python sfg.py 1stRCLPF --mode transfer

# Save a run to a new directory
python sfg.py 2Stage_OTA --output runs/my_ota

# List examples and command-line options
python sfg.py --list-examples
python sfg.py --help

For paths, loops, and analysis, Python graph analysis is the default. It enumerates simple paths/cycles and preserves distinct parallel edges. --analysis-backend legacy selects the original C++ routines. Transfer mode always invokes the C++ routines.

Additional options include --no-plot, --timeout, --max-walks, and --count TEXT. See the complete command reference.

Describe a circuit

Inputs are plain-text .isc files. Circuit nodes are numbered from 1 through the declared node count; 0 denotes ground. Use underscore-separated records, place the input/output connections first, and end the file with END.

Continuous-time example

A node-count header followed by the circuit connections:

2
VI_1_1
2_1_VO
1_G1_2
2_C1_0
END

This is the first-order RC low-pass example: conductance G1 connects input node 1 to output node 2, with capacitance C1 to ground.

Switched-capacitor and transistor examples

Use two header lines: phase count, then node count. Switch labels S1, S2, and so on identify their active phases. Single-phase transistor inputs start with a phase count of 1.

2
5
VI_1_1
5_1_VO
3_OP-_4
2_C1_0
4_C2_3
1_S1_2
4_S1_5
2_S2_3
END
RecordMeaning
SOURCE_ELEMENT_DESTINATIONA conductance, capacitor, op-amp, or switch branch.
VI_1_NODEUnit-weight input connection.
NODE_1_VOUnit-weight output connection.
DEVICE_GATE_DRAIN_SOURCETransistor record, for example M0_8_4_7 or P1_4_4_5.

Explore the results

The HTML report combines the graph, exact edge expressions, and downloadable data. Long gains use short edge IDs in the image, with complete expressions in the legend.

FilesContents

paths.tsv, loops.tsvNode/edge sequences for the selected analysis.
path_gains.txt, loop_gains.txtSymbolic path and loop products.
transfer_function.txtNumerator and denominator strings in transfer mode.
run.jsonEngine, mode, source provenance, timing, and counts.

Run the full example set

# Generate all example graphs
python run_examples.py

# Include forward paths and cycles
python run_examples.py --mode analysis

# Select a fresh output directory
python run_examples.py --mode analysis --output-root runs/all_examples

# Run the package tests
python -m unittest discover -s tests -v

Each example gets its own directory. A batch index.html links the resulting reports.
