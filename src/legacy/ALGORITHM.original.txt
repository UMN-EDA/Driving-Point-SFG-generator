ALGORITHM TO MAKE SEPARATE SUB CIRCUITS FOR DIFFERENT PHASES
1. First read the circuit file and implement all the nodes and branches irrespective of switches/phases.
2. for loop for n no. of times where n is the no. of phases in the circuit.
3. Take one switch at a time and remove all branches containing other switches and copy it into a new map. 




////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////
STEPS TO FIND THE INTER SFG BRANCHES

    Take 1 voltage source at a time
	Check caps connected to it from CKTX
	Find the voltage node in SFGFINAL...(Make sure to check its flag before searching the node)
	Extract the input and output branches of the node
	Take one capacitor at a time
		Check which i/p or o/p branch is having this capcitor
			If none...then it must be connected to the ground
		Now move to the next phase and search all nodes and see which is having that capacitor from CKTX 
			Find that respected voltage node again in the SFGFINAL (Make sure to check the flag before looking for the node in the SFG)
			Check all its i/p and o/p branches of the node and look for the capacitor
			If nowhere, then it must be grounded
			Draw the branch in SFG from the very first VOLTAGE NODE to the PRESENT NODE in the new phase
